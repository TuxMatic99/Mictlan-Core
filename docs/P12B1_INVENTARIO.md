## Diferencias verificadas con la referencia histórica

El [manual de Latino](https://manual.lenguajelatino.org/es/stable/librerias/Cadena.html) se contrasta con código y ejecución. Los códigos indican diferencias concretas; «—» no convierte el manual en especificación de casos no documentados.

| Código | Diferencia |
|---|---|
| M1 | Los índices y longitudes heredados son bytes, no caracteres Unicode. |
| M2 | comparar devuelve el resultado de strcmp; solo el signo es portable. |
| M3 | El cuarto argumento limita sustituciones; no es una posición. |
| M4 | El relleno aplica n − bytes(base) + 1 repeticiones cuando es positivo. |
| M5 | La caja se convierte por byte C, no con reglas Unicode completas. |
| M6 | separar interpreta un conjunto de bytes y descarta campos vacíos. |
| M7 | char/bytes trabajan con bytes C; no son conversiones de puntos de código. |

Las columnas de argumentos inválidos recogen validaciones B1 además de los errores de tipo heredados. La evidencia previa conserva accesos inválidos y fugas; no se promete compatibilidad con resultados de comportamiento indefinido.
