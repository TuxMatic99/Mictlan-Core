# Programas originales de Latino

Los siete archivos `.lat` se copiaron byte por byte de `ejemplos/` en el commit `8cc81faea691928b5806c0badac50701ea984e85` del proyecto Latino. Se conserva `LICENSE.txt` de esa revisión. [Ejemplos originales](https://github.com/lenguaje-latino/latino/tree/8cc81faea691928b5806c0badac50701ea984e85/ejemplos).

El verificador ejecuta cada programa como `.lat` y como `.mict`. Compara las dos salidas y comprueba valores representativos. La prueba histórica `coverage` conserva por separado una comparación exacta de toda su salida. El caso `42-menu` recibe dos argumentos y verifica el nombre de archivo como primer valor.
