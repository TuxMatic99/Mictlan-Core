
# Mictlán Alfa 0.1 para Debian

Paquete experimental del intérprete de consola Mictlán.

## Plataforma

Distribución inicial para Debian AMD64.
Las demás plataformas todavía no están verificadas.

## Uso

Después de instalar el paquete, ejecutar:

    mictlan /usr/share/mictlan/ejemplos/hola_mictlan.lat

Para ejecutar un programa propio:

    mictlan /ruta/al/programa.lat

## Dependencias

El paquete utiliza las bibliotecas compartidas
disponibles en el sistema Debian.

Las dependencias concretas se generan durante
el empaquetado y deben revisarse antes de publicar.

## Desinstalación

La desinstalación se realizará mediante el
gestor de paquetes de Debian.

Los programas personales del usuario no forman
parte del paquete y no deben eliminarse.
